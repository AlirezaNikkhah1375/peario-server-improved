# Release Notes - PearIO Server

## Version: v2.4.0-20251130

**Release Date:** November 30, 2025  
**Release Type:** Feature Release - Socket.io Migration

---

## Overview

This release migrates the WebSocket implementation from the native `ws` library to **Socket.io v4.8.1**, providing improved connection management, automatic reconnection support, and better scalability features.

---

## What's Changed

### Dependencies

#### Added
- `socket.io@^4.8.1` - Modern real-time bidirectional event-based communication library

#### Removed
- `ws@^8.6.0` - Native WebSocket library (replaced by Socket.io)
- `@types/ws@^8.5.3` - TypeScript types for ws (no longer needed)

#### Removed Configuration
- `INTERVAL_CLIENT_CHECK` - No longer needed as Socket.io handles connection tracking automatically

---

## New Features

### 1. Automatic Connection Management
- Socket.io automatically handles client connection tracking
- Built-in ping/pong heartbeat mechanism (replaces manual 2-second heartbeat)
- Automatic cleanup of disconnected clients

### 2. Native Room Support
- Clients now join Socket.io rooms using `socket.join(roomId)`
- Broadcasting to rooms via `io.to(roomId).emit()`
- Broadcasting to room except sender via `socket.to(roomId).emit()`

### 3. TypeScript Type Safety
- New typed event interfaces for compile-time type checking
- `ClientToServerEvents` - All client-to-server event types
- `ServerToClientEvents` - All server-to-client event types
- `InterServerEvents` - For future multi-server scaling
- `SocketData` - Custom data attached to each socket

### 4. CORS Configuration
- Built-in CORS support via Socket.io options
- Configurable via `CORS_ORIGIN` environment variable
- Defaults to `*` (all origins) for development

## Breaking Changes

### Environment Variables
- **Removed:** `INTERVAL_CLIENT_CHECK` - No longer needed
- **Added:** `CORS_ORIGIN` - Configure allowed origins (optional, defaults to `*`)

### Client Compatibility
- Clients must upgrade to Socket.io client to connect
- Native WebSocket clients will no longer work

---

## Event Protocol

All events remain unchanged - only the transport mechanism has changed:

| Event | Direction | Payload |
|-------|-----------|---------|
| `user.update` | Client → Server | `{ username: string }` |
| `room.new` | Client → Server | `{ meta: Meta, stream: Stream }` |
| `room.join` | Client → Server | `{ id: string }` |
| `room.message` | Client → Server | `{ content: string }` |
| `room.updateOwnership` | Client → Server | `{ userId: string }` |
| `player.sync` | Client → Server | `{ paused, buffering, time }` |
| `ready` | Server → Client | `{ user: User }` |
| `user` | Server → Client | `{ user: User }` |
| `room` | Server → Client | Room object |
| `sync` | Server → Client | Room object |
| `message` | Server → Client | `{ user, content, date }` |
| `error` | Server → Client | `{ type: string }` |

## Migration Guide

### For Server Operators

1. Update environment variables:
   ```bash
   # Remove (no longer used)
   # INTERVAL_CLIENT_CHECK=3000
   
   # Add (optional)
   CORS_ORIGIN=https://your-client-domain.com
   ```

2. Install new dependencies:
   ```bash
   pnpm install
   ```

3. Rebuild the server:
   ```bash
   pnpm build
   ```
